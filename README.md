# 🚀 WhatsApp 2 (Mikeedev Style)

Este é o **WhatsApp 2**, um aplicativo de chat em tempo real moderno com visual minimalista e modo escuro, inspirado nos projetos de código rápido do Mikeedev.

## 🛠️ Tecnologias Utilizadas
* **HTML5 & CSS3** (Interface limpa e responsiva)
* **Node.js & Express** (Servidor Backend)
* **Socket.io** (Comunicação em tempo real sem delay)

## 💻 Como rodar no seu computador
1. Baixe o código do projeto
2. Abra o terminal na pasta e instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor:
   ```bash
   npm start
   ```
4. Acesse no seu navegador: `http://localhost:3000`
